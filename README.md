# Shopfront Agent

**A store for every seller, buyable by every agent, settled by PayPal.**

Small sellers who live on social media have no website and no product feed, so AI shopping agents can't buy from them. Shopfront Agent turns a seller's product photos into a PayPal-backed catalog that any MCP-capable agent can search, order from and pay through. The agent shops; the human approves in PayPal. The seller's own AI agent then handles tracking, customer messages and policy-bound refunds.
